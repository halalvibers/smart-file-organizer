## How to use
1. Make sure you have Python installed.
2. Download `file_organizer.py`.
3. Run it in your terminal: `python file_organizer.py`.
4. Paste the path of your messy folder when prompted.

## Features
* Automatically sorts files by type.
* Safely skips unknown files to prevent errors.
* Prevents data loss by checking existing paths.
